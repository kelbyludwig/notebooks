## python notebooks

* `blind-signatures.ipynb` - Examples of Chaum blind signatures

* `fiat-shamir-heuristic.ipynb` - Some notes on the Fiat-Shamir heuristic

* `camenisch-lysyanskaya-signatures.ipynb` - Notes on CL signatures and zero knowledge proofs.

* `p-256.ipynb` - A small snippet for working with P-256 curves in Sage.

* `ecdsa-is-weird.ipynb` - Demonstrates unexpected properties of ECDSA signatures.

* `discrete-log-zero-knowledge-proof.ipynb` - A zero-knowledge proof of a discrete log, and turning it into a signature. Some sections are unfinished.

* `one-way-accumulators.ipynb` - Notes and a toy implementation of Benaloh and de Mare's one-way accumulators. Unfinished.

* `modulo-bias.ipynb` - Visualizes the bias from reducing a random value modulo a number that does not divide the range.

* `universal-hashing.ipynb` - Notes on collisions in `(a*x + b) % p` style hashes. Unfinished.

* `bezier.ipynb` - An animation of quadratic Bezier curves built from linear interpolation.

* `sage-graphics.ipynb` - Examples of Sage's plotting functions.

* `dh-distribution.ipynb` - Why Diffie-Hellman outputs should go through a KDF, with a bit-distribution plot. Draft.

* `(EC)DSA Q&A.ipynb` - Questions and answers about DSA, ElGamal, and the two moduli in (EC)DSA.

* `AES, from Scratch.ipynb` - An AES-128 implementation following FIPS 197. Unfinished: `aes128` does not yet pass the test vector.
